# Contributing

Thank you for your interest in Spine Angles.

## Bug reports and suggestions

These are welcome. Please open an issue and include what you did, what you expected, what happened, and the device and browser you used. Do not attach images that contain patient information.

## Code contributions

This project does not accept outside code contributions unless a contributor agreement with Wolfray Applied Technologies, LLC is in place first. Pull requests opened without one will be closed without being merged.

The reason is ownership: Wolfray Applied Technologies, LLC keeps sole copyright in this code so that it remains free to license future versions on other terms. Merging code owned by someone else would remove that freedom.

If you would like to contribute code, open an issue describing what you have in mind before writing anything, and an agreement can be arranged.
